# 思考强度滑条

把当前模型的思考档位做成一条可拖动的滑条，直接并入输入框底部原有的模型选择器——**一个组件、一条滑条、右侧保留原生箭头**。

## 用法

- 拖动滑条即可改变思考强度，松手生效；也可以直接点按某个档位。
- 点击滑条右侧的箭头（或组件任意空白处），展开的仍是 DSH 原生的模型菜单：模型列表、模型搜索、分组，以及「启用智能体团队协作」开关。
- 提示：箭头展开的菜单里也有一行「推理等级」，两处调节同一个值，始终同步。

## 与原生菜单的关系

滑条读写的是与原生菜单**同一个**会话级模型目录，因此拖动滑条后打开菜单看到的是新档位，在菜单里改档后滑条也会跟随。

## 按模型记忆

每个模型最近一次选定的档位保存在本地浏览器里。切回某个模型时，滑条会恢复该模型上次的档位。

## 限制

- 当前模型没有声明思考档位（或只有一档）时，滑条不渲染，原生模型选择器完全保持原样。
- 会话正在进行模型切换时，滑条临时禁用，避免覆盖尚未落定的选择。
- 滑条嵌在原生触发按钮内部，因此键盘操作仍走原生按钮（回车打开菜单，在「推理等级」中上下选择），滑条本身面向指针操作与拖动。
